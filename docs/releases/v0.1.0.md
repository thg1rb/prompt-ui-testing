- Real SSO/MFA handoff, authorized browser-profile reuse, measured retry bounds, minor UI drift, lazy loading, toast-specific behavior, and hot reload remain untested.
- Runtime validation covers Codex CLI on macOS. ChatGPT desktop Plugin runtime and other operating systems are not runtime validated.
- URL metadata redaction does not conceal sensitive content visible in page pixels.

## Outstanding external publication step

The Plugin package has not been submitted to the public OpenAI Plugins Directory. The current [submission process](https://developers.openai.com/plugins/deploy/submission) requires a verified publisher identity and Apps Management submission access, followed by review and an explicit publish action after approval. The submission portal was not accessible through the tools available in this release session. Do not describe the Plugin as publicly listed until the portal confirms publication.
