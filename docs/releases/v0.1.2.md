## Known limitations

- Native Chrome Incognito UI and true OS fullscreen are not required or guaranteed; maximization is best-effort.
- Browser runtime validation for this change covers macOS only. Other operating systems and display environments are not runtime validated.
- Real SSO/MFA handoff and persistent authenticated-profile reuse remain untested. Supplied synthetic storage-state restoration was exercised as an explicit exception to the fresh-session default.
- Other control, dynamic UI, retry, and evidence limitations remain as listed in the [README](../../README.md#safety-and-limitations).
