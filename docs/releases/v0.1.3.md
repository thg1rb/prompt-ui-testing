## Known limitations

- Fullscreen runtime validation covers macOS only. Other operating systems and explicit multi-monitor placement are not validated; the browser/OS chooses the display.
- Maximized mode is the fallback when Fullscreen cannot be established. Headless execution does not provide visible desktop Fullscreen.
- Native Chrome Incognito UI is not required, and Computer Use is not a dependency.
- Other control, dynamic UI, authentication handoff, retry, and evidence limitations remain as listed in [README](../../README.md#safety-and-limitations).
