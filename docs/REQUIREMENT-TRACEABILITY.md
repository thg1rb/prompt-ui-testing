Status meanings: `PASS` means the required behavior or static condition has adequate evidence; `PARTIAL` means some supported variants or environments remain unverified; `NOT TESTED` means no adequate evidence was available; `NOT APPLICABLE` means the criterion does not apply; `BLOCKED` means the environment prevented validation; `FAIL` means observed behavior violated the requirement. A test whose expected Agent outcome is BLOCKED or FAIL can still have matrix status PASS when the Agent classified and reported it correctly. Existing evidence is reused unless a new scenario is cited.
